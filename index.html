Projects

01

MediAlert — IoT Medication Monitoring System

An IoT medication reminder and monitoring system on a Raspberry Pi. Reminders, sensor polling and connectivity run on three separate threads, so a slow network call can't block a time-critical alert. Telemetry flows through Azure IoT Hub, Stream Analytics and Power BI, with retry logic and local logging so device state survives restarts and failed cloud sends. Debugging it surfaced two real data-integrity bugs — including a temperature sensor silently reporting Fahrenheit while the rest of the pipeline assumed Celsius.

NOMO — Survival/Exploration Game

Built to learn the full game development pipeline end to end — not just gameplay, but the architecture underneath it. Systems communicate through events rather than direct references, so player state, inventory, quests, status effects and AI can be extended or swapped without touching unrelated code. That same decoupling made it possible to add a slot-based save system that serialises the entire world state without every system needing to know how saving works.

An Android app for reporting and finding lost property. Built on MVVM: Compose screens own the UI, view models hold state and logic, and a repository layer sits between them and Room/Firebase so neither has to know about the other directly.
